Griedon Embeds

A private, free web dashboard for designing, scheduling, and managing rich Discord messages — supporting both Components V2 Layouts and Classic Embeds.

How to Get Started

  1. Add the App: Click Add App on the bot's Discord profile to invite it to your server.
  2. Get Approved: The bot is currently invite-only. Join the support server and ask the owner to approve your server request.
  3. Log In: Open the Dashboard and sign in with Discord (only server Administrators can access their server's messages).

Features & Bot Guide

Components V2 & Classic Embeds Build modern layouts with Boxes, Sections, Image Galleries, Dividers, Button Rows, and Dropdowns — or classic embeds (up to 10 per message).
Interactive Buttons & Dropdowns Attach Link buttons, Role toggles/add/remove, Private Replies, Pop-up Forms (up to 5 questions), and Cooldown / Once-per-person rules.
Permanent Discord Variables Use the {x} Var picker in the formatting toolbar to insert live placeholders like {{usermention}}, {{servername}}, {{membercount}}, and {{date}}.
Paginated Embeds Add extra pages with + Page and wire Next / Previous / Page buttons so members can flip pages right inside Discord.
Scheduling & Sequences Schedule one-time, daily, or weekly posts/updates in your timezone, or group saved messages into a Sequence to post in order.
Webhooks, Templates & Backups Post under custom webhook names & avatars, reuse templates from the Starter Gallery, edit Raw JSON, and export/import full server backups.
