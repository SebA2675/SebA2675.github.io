Visual Step-by-Step Guide

Everything you need to go from inviting the bot to building interactive Discord layouts.

1. Invite the Bot & Check Live Status

Start on nation9.me and click + Invite Bot to add 9NATION EMBEDS to your Discord server. You can check bot health, gateway ping, and uptime anytime on the Status page.

2. Sign In with Discord & Pick Your Server

Open the Dashboard and click Log in with Discord. Once signed in, you'll land on My Servers — click Open dashboard on any approved server to enter its isolated workspace.

3. Inside Your Server Workspace

Every server is completely independent. Use the left sidebar (or the ☰ menu on phones) to jump directly to:

Messages & SchedulesCreate Components V2 or Classic Embeds, search drafts, and manage all scheduled posts.
AutomationDedicated pages for Welcome & Goodbye, Keyword Replies, Social Feeds, Custom /faq, and Sticky Messages.
Server ToolsBackups, Discord Link & Discohook JSON import, Templates, Sequences, Webhooks, Brand Kit, Teamwork & Trash.

4. Interactive Builder Walkthrough (In-App Spotlight Tour)

When you open a message in the Builder for the first time, an interactive in-game spotlight tutorial automatically highlights each panel and explains what it does:

  • Message Tree: Drag rows to reorder, or collapse the tree to keep Add buttons close.
  • Add a Part: Click Box, Text, Section, Images, Divider, Buttons, or Dropdown.
  • Live Preview: Click any part directly in the preview to edit it, or toggle Test mode to click buttons.
  • Part Settings: Edit formatting, custom emojis, button actions (Links, Replies, Forms, Roles), and cooldown rules.
  • Send & Schedule: Publish to any Discord channel, update live posts, or set recurring schedules.
