About 9NATION EMBEDS

Last updated 25 November 2026

9NATION EMBEDS is a dedicated Discord Embed & Components V2 Layout Studio built by the 9 Nation team. It lets server administrators and trusted editors design, preview, schedule, and automate rich Discord messages from one clean, per-server dashboard.

What the Bot Does

  • Components V2 & Classic Embeds: Visual builder for Boxes, Sections, Image Galleries, Dividers, Buttons, Dropdowns, and Classic Embeds (up to 10 per message).
  • Interactive Systems: Private ephemeral replies, 5-question pop-up Forms with Accept/Deny logs & CSV export, Self-Role Menus, Multi-Page Embeds, and /faq slash commands.
  • Per-Server Automation: Welcome/Goodbye layouts, Keyword auto-replies, RSS/YouTube/Reddit feeds, Sticky messages, and recurring Schedules.
  • Team & Safety Tools: Editor Access without Discord Administrator, Brand Kits, JSON Backups, Discohook Import, 30-day Trash restore, and Version History.

Who Can Use It

Access is currently invite-only for approved servers. Server Administrators (or Editors granted access inside Server Tools) can manage only their own server's independent workspace.

How Discord Sign-In Works

Signing in uses Discord OAuth2 with the minimal identify scope, which checks your Discord user ID and server permissions. It never asks for your password and cannot read your private messages, emails, or friend list.
