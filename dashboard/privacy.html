Privacy Policy

Last updated 25 November 2026

This Privacy Policy explains what data 9NATION EMBEDS collects, why it is needed, how long it is kept, and how you can delete it at any time.

1. Data We Store

  • Discord User IDs: Used to verify dashboard permissions, enforce button cooldowns / once-per-person locks, and track editor access lists.
  • Saved Messages & Configuration: Draft names, layouts, embed text, image URLs, buttons, dropdowns, forms, replies, schedules, templates, webhook presets, Brand Kit settings, and the last 20 saved versions per message.
  • Automation & Feeds: Welcome/Goodbye channel & message mappings, keyword triggers, RSS/YouTube/Reddit feed URLs, sticky message configs, and /faq entries.
  • Server Identifiers & Logs: Approved server IDs/names and recent dashboard activity logs (edits, posts, deletions) for server auditing.

2. Data We Never Collect or Store

  • No Discord passwords, account tokens, email addresses, or private DMs.
  • No bulk logging of general Discord chat messages (only messages matching an active Keyword trigger or Sticky channel check are evaluated in memory).
  • No third-party ads, analytics trackers, or tracking cookies. Session tokens are stored only in your browser's localStorage and invalidated when you click Sign out.
  • IP addresses are used strictly in memory for rate-limiting and are never written to disk.

3. Retention & Backups

  • 30-Day Trash: Deleted messages stay in your server's Trash for 30 days for recovery before permanent purge.
  • Automated Backups: Encrypted nightly database backups are retained for up to 14 days for disaster recovery.

4. Your Data Rights & Deletion

Server administrators can export all server data as JSON or permanently wipe all saved drafts, automation, and settings for their server anytime using Team, Trash & Logs → Delete all server data. Data is never sold or shared with third parties.
